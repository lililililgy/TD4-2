==================================================
        ONEngine 開発環境スタートガイド
==================================================

本パッケージには、VisualStudioを開くことなく、C#スクリプトの編集とゲーム実行ができる開発環境が整っています。

■ 動作要件
- .NET SDK (特に 'dotnet' コマンド) がインストールされ、環境変数 PATH が通っている必要があります。
  未インストールの場合は、Microsoft公式サイトより .NET SDK (推奨 v8.0 または v10.0) をインストールしてください。

■ 起動方法
1. ルートにある「Launch.bat」をダブルクリックします。
   （または Project/ONEngine.exe を直接実行することも可能です）

■ C#スクリプトでの開発手順
1. 「SubProjects/CSharpLibrary/Scripts」以下にC#スクリプト（.csファイル）が配置されています。
2. VS Code、メモ帳、サクラエディタなど、お好みのテキストエディタでこれらのC#コードを編集・保存します。
3. 保存すると、エンジンの起動時、およびゲーム実行中に自動的にコンパイルが走り、最新の変更内容が即座にゲーム内にホットリロードされます。
4. コンパイルエラーがある場合は、エンジン内のログ画面（ImGui）にエラー内容が表示されます。

■ デバッグ方法（VS Code推奨）
1. VS Code を開き、このフォルダ（ONEngine_DevEnv）をワークスペースとして開きます。
2. 拡張機能「Mono Debug」および「C#」をインストールします。
3. F5キーを押してデバッガーを起動し、起動中の ONEngine にアタッチすることでデバッグ（ブレークポイント、ステップ実行）が可能です。
