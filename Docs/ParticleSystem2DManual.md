# ParticleSystem2D コンポーネント使用マニュアル

`ParticleSystem2D` は、XY平面上（Z = 0）で動作する2D特化型のパーティクルシミュレーションおよび描画を行うコンポーネントです。UnityのParticle System（Shuriken）に似たモジュール構成を持ち、インスペクタからの多彩なパラメータ編集や、スクリプトからの再生制御に対応しています。

---

## 1. 前提条件と基本構造

パーティクルを発生・描画させたい Entity には、以下のコンポーネントがアタッチされている必要があります。
* **`ParticleSystem2D`**: パーティクルの寿命、速度、カラー、サイズなどのシミュレーションデータを保持・管理します。
* **`Transform`**: パーティクルエミッター（放出源）の位置、回転、スケールを決定します。

### シミュレーション平面について
`ParticleSystem2D` は2Dに特化しているため、パーティクルの初期位置や速度の **Z軸成分はシミュレーション時に強制的に `0.0f` にリセット** されます。

---

## 2. エディタ（インスペクタ）での設定項目

インスペクタ上で `ParticleSystem2D` コンポーネントを展開すると、以下のモジュールとパラメータが表示され、リアルタイムに動作を確認できます。

### 2.1 Editor Preview & Controls (プレビュー・制御)
エディタ実行中でなくても、インスペクタからパーティクルのプレビュー再生や、ゲーム実行中の挙動を制御できます。

* **Editor Preview (エディタ用)**
  * **Preview Play**: エディタ上でシミュレーションのプレビューを開始します。
  * **Preview Pause**: プレビューを一時停止 / 再開します。
  * **Preview Stop**: プレビューを停止し、パーティクルをクリアします。
  * **Preview Restart**: プレビューを最初からやり直します。
* **Runtime Status (ゲーム実行用)**
  * **Play / Pause / Stop / Restart**: ゲーム実行時のパーティクル再生状態を操作します。

---

### 2.2 Main (メイン設定)
パーティクルシステム全体の基本挙動を設定します。

| パラメータ | 型 | 説明 |
| :--- | :--- | :--- |
| **Duration** | `float` | システムの再生時間（秒）。ループしない場合、この時間が経過すると放出が停止します。 |
| **Looping** | `bool` | 有効にすると、`Duration` 経過後に自動で最初から再生（ループ）します。 |
| **Prewarm** | `bool` | ループ再生時に、最初から1サイクル分シミュレーションが進んだ状態で開始します。 |
| **Start Delay** | `MinMaxFloat` | 再生開始から実際にパーティクルが放出されるまでの遅延時間（秒）。 |
| **Start Lifetime** | `MinMaxFloat` | パーティクル個体の寿命（秒）。 |
| **Start Speed** | `MinMaxFloat` | パーティクル個体の初期速度。 |
| **Start Size** | `MinMaxFloat` | パーティクル個体の初期サイズ。 |
| **Start Rotation** | `MinMaxFloat` | パーティクル個体の初期回転角度（ラジアン）。 |
| **Start Color** | `MinMaxColor` | パーティクル個体の初期カラー。 |
| **Gravity Modifier** | `float` | 重力の影響力係数。`1.0` で標準の重力 `(0, -9.81, 0)` がXY平面に適用されます。 |
| **Simulation Space** | `Enum` | `World`（ワールド座標系）または `Local`（エミッターのローカル座標系）のどちらで物理シミュレーションを行うかを選択します。 |
| **Max Particles** | `int` | システム内で同時に存在できる最大パーティクル数。 |

> [!NOTE]
> **MinMaxFloat / MinMaxColor について**
> パラメータの型が `MinMaxFloat` や `MinMaxColor` のものは、定数値（`Constant`）のほかに、「2つの定数の間からランダム（`RandomBetweenTwoConstants`）」などを選択して、放出時にバラつきを持たせることができます。

---

### 2.3 Emission (放出設定)
パーティクルがどのように、どのくらいの頻度で放出されるかを設定します。

* **Rate over Time**: 1秒間に放出するパーティクル数。
* **Bursts (バースト)**: 特定のタイミングでパーティクルを一括放出する設定リスト。
  * `+` ボタンでバースト設定を追加でき、`x` ボタンで削除できます。
  * パラメータは左から順に **[放出タイミング（秒）]**, **[放出個数]** です。

---

### 2.4 Shape (放出形状設定)
パーティクルが放出される領域の形状と、初期速度の方向を定義します。

* **Shape Type (形状タイプ)**:
  * **Sphere / Circle**: 2Dの円形領域から放出します。初期速度は中心から外側へ向かう放射方向になります。
  * **Hemisphere**: Y軸正方向（上半分）の半円領域から放出します。
  * **Box**: 指定した矩形領域からランダムに放出します。初期速度はY軸正方向（真上）です。
  * **Cone**: 2Dの扇形（コーン）領域から放出します。
  * **Edge**: X軸上の線分領域から放出します。初期速度はY軸正方向（真上）です。
* **形状固有のパラメータ**:
  * **Radius**: 円、半円、コーン、エッジの半径（幅）。
  * **Radius Thickness**: 放出領域の厚み（`0.0` 〜 `1.0`）。`1.0` で円全体、`0.0` に近づくと円周付近からのみ放出されます。
  * **Arc**: 円やコーンの放出角度範囲（度数法、最大360度）。
  * **Angle**: コーンの広がりの角度。
  * **Box Scale**: `Box` 選択時の矩形サイズ（X, Y, Z）。（Z成分はシミュレーション時に無視されます）

---

### 2.5 Color over Lifetime (寿命による色変化)
パーティクルの生存時間（Lifetime）の経過に伴う色の変化を制御します。

* **Color**: `MinMaxGradient` を使用して、寿命の開始（0%）から消滅（100%）までのカラーグラデーションを設定します。初期カラー（`Start Color`）に乗算されます。

---

### 2.6 Size over Lifetime (寿命によるサイズ変化)
パーティクルの生存時間の経過に伴うサイズのスケール変化を制御します。

* **Size**: `MinMaxCurve` を使用して、寿命に応じたサイズの変化割合（カーブ）を設定します。初期サイズ（`Start Size`）に乗算されます。

---

### 2.7 Velocity over Lifetime (寿命による速度変化)
パーティクルの移動速度に対して、時間経過に伴う追加の速度や制限を適用します。

* **Linear X / Y**: 時間経過に伴って適用されるX軸・Y軸方向の追加速度カーブ。
* **Speed Modifier**: 全体の速度に対する乗算マルチプライアカーブ。
* **Space**: 追加速度を `Local`（エミッターの向きに追従）または `World`（ワールド絶対方向）のどちらで適用するかを選択します。

---

### 2.8 Renderer (レンダラー設定)
パーティクルの描画方法をカスタマイズします。

* **Render Mode**:
  * **Billboard**: 常にカメラの方向を向くクワッド（四角形）として描画します（標準）。
  * **StretchedBillboard**: パーティクルの移動速度に応じて引き伸ばされたクワッドを描画します。
    * **Speed Scale**: 速度による引き伸ばし量。
    * **Length Scale**: パーティクルの長さスケール。
  * **HorizontalBillboard / VerticalBillboard**: 特定の平面に沿ったビルボード。
  * **Mesh**: 任意のカスタム3D/2Dメッシュ（.obj等）をパーティクルとして描画します。
* **Render Alignment**:
  * **View**: カメラ向きに整列します。
  * **Velocity**: 移動速度の方向に向きを整列させます。
* **Blend Mode (合成モード)**:
  * `Normal` (アルファブレンド), `Add` (加算), `Subtract` (減算), `Multiply` (乗算), `Screen` (スクリーン) から選択します。
* **Flip Mode**:
  * テクスチャを `X`方向, `Y`方向, または `Both`（両方）に反転させます。
* **Material**: 描画に使用するマテリアルアセットのGUID。
* **Mesh**: `Render Mode` が `Mesh` の場合に使用するカスタムメッシュのGUID。

---

### 2.9 Texture Sheet Animation (テクスチャアニメーション)
パーティクル画像にグリッド分割された連番スプライトシートを使用し、アニメーション表示させます。

* **Tiles X / Y**: テクスチャを横（X）および縦（Y）に分割するグリッド数（例: 4x4分割なら `Tiles X: 4`, `Tiles Y: 4`）。
* パーティクルの生存時間（0%〜100%）に合わせて、左上から順に自動でパラパラアニメーションが再生されます。

## 3. C++ スクリプトからの制御 (API)

C++のゲームロジックやECSシステムから `ParticleSystem2D` コンポーネントを取得し、プログラムから操作するための主要なAPIです。

### 3.1 制御用メソッド
```cpp
// シミュレーションの再生を開始します（再生タイマー、生存カウント、バースト情報をリセットします）
void Play();

// シミュレーションの放出を停止します（既存のパーティクルは寿命が尽きるまで消えません）
void Stop();

// パーティクルシステムをクリアします（再生時間を0に戻します）
void Clear();

// シミュレーションを一時停止します
void Pause();

// シミュレーション時間を手動で進めます
void UpdateTime(float dt);

// 再生時間を指定した時間（デフォルト0.0f）にリセットします
void ResetTime(float t = 0.0f);
```

### 3.2 状態取得メソッド
```cpp
// システムが現在再生中かどうかを取得します
bool IsPlaying() const;

// システムが現在一時停止中かどうかを取得します
bool IsPaused() const;

// 現在の再生経過時間を取得します
float GetTime() const;
```

## 4. レンダリングと描画順（ソートシステム）

2Dゲームにおいて、パーティクルと他のオブジェクト（スプライトや背景など）の前後関係は非常に重要です。

`ParticleSystem2D` では、描画時に**エミッター（アタッチされているEntity）の Z座標 を基準に、奥から手前へ（降順に）自動ソート**して描画コマンドを発行します。

* **描画順 of 制御**:
  * Entityの `Position.z` が大きいもの（奥）から順にレンダリングされます。
  * パーティクルを他のスプライトの手前に表示したい場合は、Entityの Z座標 を他のオブジェクトより手前（カメラに近い値、通常はより小さいZ値）に調整してください。
